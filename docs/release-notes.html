What changes from one version of Aster to the next.

1.0 Coming soon

The first version on the Mac App Store.

  • A library made of your Finder folders, with an XMP file beside each photo.
  • Safe import from memory cards, cameras and folders, with verified copies.
  • RAW development with a render frozen per photo, and lens corrections from Lensfun.
  • Local retouching: masks, luminance and colour ranges, automatic masks for people, skin, subject and sky, Healing.
  • Titles in batches, and file renaming from them.
  • Search by date and camera, smart albums.
  • Export to JPEG and TIFF with your own naming.
